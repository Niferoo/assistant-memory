# Backup Policy (minimum critical)

This repository stores only hard-to-recover OpenClaw data.

## Included
- `MEMORY.md`
- `memory/**`
- `USER.md`
- `SOUL.md`
- `IDENTITY.md`
- `TOOLS.md`
- `AGENTS.md`
- `HEARTBEAT.md` (when customized)

## Excluded
- `BOOTSTRAP.md` (one-time onboarding)
- temporary/system/cache files
- installed built-in skills under npm `node_modules`
- secrets/tokens/auth files (never commit)

## Remote
- `git@github.com:Niferoo/assistant-memory.git`
